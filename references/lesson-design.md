# 教学设计与 Markdown 初稿

## 把设计原则落到这位读者身上

学情分析的作用是决定从哪里开始、铺垫多少、哪些内容可以略过。优先确认与主题有关的能力，不给读者贴“视觉型学习者”等固定标签。

| 已知情况 | 对写法的影响 |
| --- | --- |
| 知道术语，但不能解释过程 | 用一个可追踪案例补因果链，减少重复定义 |
| 熟悉相关数学，正在理解新系统 | 简述基础，集中解释新映射、约束与差异 |
| 缺少必要前置概念 | 先介绍看懂下一幅图需要的概念，再分步构建机制 |
| 只要知道结论或做判断 | 先结论，再提供足够的理由与边界，不强行设置悬念 |
| 背景混合或尚未确认 | 确定一条主阅读路径；基础补充与深入推导按需展开，明确暂定假设 |

选择少量实际改变写法的原则，并写出对应动作。例如：

- “读者没接触过频谱，因此先用两种周期的叠加建立对应，再介绍‘频率成分’，不从积分符号开始。”
- “读者已熟悉网络组件，因此沿一个数据块的行程讲解等待与拥塞，省略设备名词课。”
- “运动难以在脑中保持，因此先标记同一个对象，再用可暂停的连续运动展示相对位置变化。”

## 叙事要解决问题

适合时使用：具体困惑 → 现有直觉哪里不够 → 一个必要的新概念 → 可观察的解释 → 适用边界 → 下一问题。

这是可调整的组织方式，不是每节固定六段。故事感来自问题和因果逐步得到解释，不来自虚构人物、冗长背景、故意延迟答案或悬念按钮。保留读者需要的总体地图；复杂概念一次引入一个关键变化。

每个章节能够说清“读者进入时还不知道什么，离开时能判断什么”。前一节给出的认识应成为后一节的前提；不能只是把系统的组件清单换成问句。

## 一个可直接调整的初稿结构

以下是结构示例，不规定字数、章节数或媒体数量。

```markdown
# 文档标题

## 教学设计说明

读者与依据：已确认……；暂按……处理。
学习目标：读完能解释／预测／判断……。
关键障碍：容易把……误认为……。
设计原则：因为……，采用……，具体体现为……。
叙事路径：从……的问题开始，经由……，最后回答……。
范围与形式：讲到……为止；选用……，因为……。

## 第一个真实问题

可独立阅读的解释正文，以及读者已能理解的贯穿例子。

> 媒体 M1｜标题｜静态图／动画／参数实验
> 位置与目的：承接哪一句，补哪项知识缺口；支持哪个目标。
> 内容与动作：显示什么；读者操作什么；哪些量保持不变。
> 观察与解释：应看见什么，由此能够得出什么；下一段如何承接。
> 形式理由：为什么需要这种媒体，较简单的表达为何不足或已足够。
> 边界与替代：模型或素材来源、重要简化；无法运行时的静态图与说明。

正文解释刚才的观察，并自然引出下一问题。

## 后续问题与结论

逐层形成的解释、条件和一个必要的反例或检查问题。
```

媒体说明是作者与读者可审阅的方案，不是成品页面中必须原样展示的表单。简单静态图可用两句话合并字段；复杂模拟必须具体到控件、输出和关键限制。稳定编号用于讲稿与实现对应，不增加无用途的登记系统。

教学设计本身也留在交付文档里。HTML 可保留一段简短的“这篇说明如何展开”，详细设计依据置于次要区域；不要占据正文主线或把代码、内部检查状态塞进学习流程。

## 选择最低充分的媒体

| 需要学习什么 | 通常先考虑 | 何时换一种形式 |
| --- | --- | --- |
| 名称、结论、简单概念区别 | 文字、例子、小表格 | 只有空间或因果关系难以表达时增加图 |
| 组件位置、归属、依赖 | 静态关系图 | 需要追踪事件顺序时增加分步状态 |
| 同一对象随时间怎样变化 | 连续动画、短视频；简单短循环可用 GIF | 需要暂停、对照或回放时优先带控制的动画／视频 |
| 某个输入怎样改变结果 | 有指导的参数实验 | 有明确可调变量、可见结果与模型依据后才实现 |
| 两种状态有什么差别 | 同屏静态对照 | 单次静态对照已充分就不添加切换开关 |
| 手机阅读、分享、导航 | 阅读型 HTML | 不因格式变为 HTML 就增加教学交互 |

删除一个控件，若没有失去可描述的学习动作或阅读便利，就考虑删除。目录、搜索、复制属于阅读辅助，不能充当教学互动的效果证据；同样不禁止确有用途的阅读辅助。

## 理念来源与使用边界

以下是方法依据和设计参考，不是“这种页面必然有效”的证明；不要求每篇交付都重新综述教育学。

- [CMU：了解学生](https://www.cmu.edu/teaching/designteach/design/yourstudents.html)：关注读者已有知识与经历。这里将它落实为主题相关的学情判断，不用学历代替诊断。
- [Mayer 与 Moreno，2003](https://www.umassmed.edu/globalassets/pediatrics/pediatrics-residency-program/woo-insider/resources/nine-ways-to-reduce-cognitive-load-in-multimedia-learning.pdf)：从认知负担讨论分段、预备知识与删去无关内容。具体页面仍须结合任务和读者取舍。
- [Tversky、Morrison 与 Bétrancourt，2002](https://www.tc.columbia.edu/faculty/bt2158/faculty-profile/files/_Morrison_Betrancourt_AnimationCanitfacilitate.pdf)：动画的形式应匹配要表达的变化，并让人来得及看懂；不能仅凭“动起来”判断它比静态图好。
- [3Blue1Brown：傅里叶变换](https://www.3blue1brown.com/lessons/fourier-transforms/) 与 [PhET：Fourier Making Waves](https://phet.colorado.edu/en/simulations/fourier-making-waves)：分别作为连续视觉叙事、可操作参数实验的参考。借鉴组织方法，不原样复制素材，也不将示例可用性当作本次教学效果证据。
