# 从教学讲稿到 HTML

## 先有教学脚本，再决定页面结构

读取当前 Markdown 的设计说明、问题链及媒体编号，再选择布局。HTML 的价值可能来自清楚的空间关系、同屏对照、连续观察和阅读节奏，不以控件数量衡量。

围绕读者正在解决的问题组织一个连续阅读面。文字与其解释的图尽量相邻；跨节沿用对象、颜色、符号和坐标。适合时使用一幅贯穿图，随叙事增加标注；有比较任务时并排对照。小屏切为清楚的先后顺序，不靠横向压缩保留桌面布局。

不要默认使用大封面、统计卡片、每段一个圆角框、层层标签页或滚动入场动画。卡片用于确有独立边界的补充，标签页用于有选择需要的并列材料；主要推导不能被隐藏在一连串点击后。读者应能判断自己正在读哪一问、为什么看这幅图、接下来要关注什么。

## 把媒体说明变为可学的体验

每个实现对应讲稿中的媒体编号。说明读者应注意的对象，给有意义的初始状态；必要时先示范一次，再让读者改变条件。操作后更新可见结果，并就地解释变化，不只改装饰或数字颜色。

- 连续运动：提供暂停与重播，需要时提供逐步观察；不要把浏览速度与自动播放速度绑死。
- 参数实验：控件有名称、单位、合理范围和当前值；固定与本题无关的量；可重置到可解释状态。
- 对照：保持尺度、图例和对象身份一致；同屏能看清时不强迫切换。
- 阅读辅助：目录、搜索、复制按用途选择，不计入教学互动成效。

动画或媒体的职责是帮助观察。正文仍要完成解释与结论；不让读者自行猜测两者之间的因果关系。不要用“已学会”按钮、动效计数、隐藏答案或积分替代理解检查。

## 模型、来源与可访问性

数据图来自声明的数据或算法。简化仿真写清决定结果的模型、单位和关键排除项；不要把预设动画包装成真实计算，不把插画包装成实测图。

离线阅读是独立本地文档的默认选择。尽量采用本地或内嵌资源；确需联网内容时明确依赖并提供静态解释。复用网络案例前核对内容与使用条件，不以链接存在声称媒体已经嵌入、下载或测试。GIF、视频无法生成时交付明确的待实现方案或静态替代，不留一个会误导读者的空播放器。

基础正文在脚本未运行时仍可读。提供键盘操作、可见焦点、图像说明和不只依赖颜色的区分；响应减少动态效果偏好。自动运动不妨碍读正文，减少动画模式下保留关键状态与结论。

## 来源一致性与修改

Markdown 是教学设计和讲解内容的权威来源；数据、模型代码和结构图也各有一个权威位置，引用已有项目材料即可。HTML 是派生呈现，不成为第二份独立维护的结论。

记录所用 Markdown 与关键数据／模型的版本或摘要，以及生成方法。有现成生成器就复用；一次性页面不为形式完整另建通用框架。没有可重跑的生成入口时，如实标为一次性派生页面，不声称可重复构建。

事实与教学路径变化先改源稿，再同步 HTML；实现反过来暴露设计缺陷时也回写源稿。媒体顺序、初始状态、计算范围和结论逐项对应。不强求逐字排版相同，不允许展示稿删去原稿的重要条件。

## 交付前核验

1. 内容：读者目标、问题链、术语前提、关键结论和限制与原稿一致；每个实际媒体都有可定位的用途。
2. 行为：真实操作每个关键控件，观察它是否改变了预定量；核验至少一个正常案例与一个有意义的边界。模型数值须有可核对的预期结果。
3. 阅读：桌面与手机宽度下检查图文相邻关系、字号、遮挡、表格和控件；核对键盘路径、暂停和减少动态效果。
4. 依赖：核验声明的离线资源、脚本关闭时的正文、链接及源稿版本；结构图按所属流程检查 freshness。

无法使用浏览器或某类媒体工具时，说明哪些检查已做、哪些未做，保留可读讲稿与替代方案。静态检查通过不等于视觉检查或交互验证通过，原型能运行也不证明读者已经掌握概念。
