# 最多五问的学情诊断

## 何时需要

仅当未知信息会实质改变讲解起点、深度、术语密度或媒体选择时诊断。先复用当前任务中已确认的背景；读者是用户之外的人时，不把用户的专业背景当成目标读者背景。

目标是找到合适的解释起点，不是给人评级或考查完整专业能力。能判断下一步即可结束，允许零问、一问或少于五问。

## 与无知审判衔接

存在可读的 `$ignorance-trial` 时，读取它的当前 `SKILL.md`。本机入口为 `${SKILLS_ROOT}/ignorance-trial/SKILL.md`；不存在时使用本文件的普通学情澄清，不自动安装。

调用时限定对象为“当前主题的读者基础与学习目标”，沿用其启动与确认规则：用户已明确要求本次先诊断时直接进入；仅自动发现需要时，先指出影响讲解的一个缺口并提议，得到确认后进入。不要为了确认而再收集一次已提供的信息。

诊断不扩展到产品目标、完整需求、资源审批或其他领域的审查。结束后只带回：已确认的基础与目标、暂定假设、需要补的前置概念、讲解深度与媒体选择的影响，然后继续教学设计，不来回转交。

## 五问是总上限

本次文档的这轮学情诊断累计最多五个实质问题。启动选择若用一个问题提出，也计入；不能每批各问五个。一个编号里要求回答数个独立事项，应按实际问题数计算，不把问卷藏进复合长句。

通常先问一到两个最有价值的问题，再据回答决定是否还需要追问。不得提前把五个问题当成必填表；“你是什么专业”只有在确实影响写法时才问。优先询问实际接触程度与短小的解释或预测，避免只靠“初级／高级”自评。

每个候选问题都要能改变一个具体设计决定；不能说明这个影响的问题不问。

## 可选问题，不必全部问

以下以傅里叶讲解为例。问题表是作者参考，不要连同“改变的决定”一列发给读者。

| 候选问题 | 改变的决定 |
| --- | --- |
| 你希望看完后能用傅里叶分析解释哪个具体问题？ | 只建直觉，还是进入计算、算法或系统应用 |
| 看到一张振幅随时间变化的图，你目前能从中读出哪些信息？ | 是否先解释坐标、周期、频率与振幅 |
| 你认为把两个不同频率的正弦波叠加，得到的曲线还会是单一正弦波吗？可以说说直觉。 | 是否需要先用叠加示例建立复合信号概念 |
| 正弦函数、积分、复数这几项中，哪些可以直接拿来解释，哪些需要先铺垫？ | 选择数学表达的起点；这是一个关于可用语言范围的选择 |
| 你以前在什么场景用过或见过频谱？ | 选择机械振动、声音或信号链等贯穿案例 |

选择题应提供清楚的接触程度或使用情境，并允许“不确定／没接触过”；不把选项写成读者无法判断的专业考试。短预测不评分，不用一次回答推断一般智力或固定能力。

## 如何收口

写入教学设计说明，例如：“已确认会读时序图，能理解频率与振幅，尚未建立复合信号的频谱表示；目标是理解振动诊断。先给叠加与频谱对应，再讲频率识别，积分放到深入部分。”

没有回答不算已确认。用户跳过、问满仍有未知或无法联系目标读者时，采用明确标注且易调整的读者假设；可提供基础补充与深入入口。若缺口会使整个成品目标无法确定，只暂缓依赖该决定的部分，不继续追加第六问或伪造学情。
